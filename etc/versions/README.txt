Versions
========

This directory contains Buildout configurations that capture component version
information.  The contents of this directory include:

dists.cfg
    Identifies non-Python packages that are typically built with the
    "configure; make install" build sequence.  In addition to download URLs,
    it specifies the MD5 hash of each package.  It also extends any known
    good sets (KGS's) of Python-based distributions we use.
known-good-versions.cfg
    This file is generated by running a full battery of tests of Plone along
    with our custom software to determine what additional components (and what
    versions of them) are needed.  Although generated, it is checked into
    revision control for use by final deployment to the destination host.
